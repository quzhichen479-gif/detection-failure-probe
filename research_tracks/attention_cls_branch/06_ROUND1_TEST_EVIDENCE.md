## 2. What is actually supported

### BRA-Lite

BRA is the strongest Round-1 candidate and nearly matches baseline mAP50-95. It increases Recall, mAP50 and mAP75, while losing about 1.35 percentage points of Precision.

The useful hypothesis for the next round is therefore **not** “larger attention is better”. It is narrower:

> content-dependent context selection appears to recover additional positives, but the selected context or the final classification response still admits too many background-like candidates.

This is a hypothesis generated by the metric pattern, not a proven causal explanation.

### CAA-Lite

CAA keeps Precision/Recall approximately unchanged and improves mAP75, but loses overall mAP50-95. It remains a useful mechanism control but is not evidence that axis-wise long-range context improves the task overall.

### LSK-Lite

LSK degrades all key metrics substantially. Stop this branch. Do not revive it by kernel sweeps, extra insertion positions, or stacking with other attention unless a new independent mechanism probe directly explains the failure.

## 3. Protocol consequence

The previously locked protocol still gives CAA its predefined second-insertion test priority. Do **not** use the Round-1 test ranking to retroactively change that earlier choice.

However, the current test has now influenced the research decision to investigate new modules such as DBRA/SHSA/Triplet Attention. Therefore:

> **For the new Round-2 candidates, the current test is no longer a pristine final holdout.**

Round-2 module selection and hyperparameter decisions must be made from the frozen validation protocol. A new final confirmation set or external dataset should be used if a future paper-level final confirmation is required.

## 4. Round-2 search target

The next candidates should preferentially test one of these hypotheses:

1. **Improve BRA-style context selection purity** rather than merely increasing receptive field.
2. **Use a lighter global correction** to see whether BRA routing complexity is actually necessary.
3. **Test cross-dimensional local feature selection** without deliberately enlarging receptive field.

This leads to the next three candidates:

- DBRA — Deformable Agent Bi-level Routing Attention;
- SHSA — Single-Head Self-Attention from SHViT;
- Triplet Attention — cross-dimensional convolutional attention.
